# Security policy

## Reporting a vulnerability

Use the [private security reporting form](https://github.com/bwmp-dev/provenance/security/advisories/new)
in this repository for vulnerabilities affecting any part of Provenance,
including the public toolkit, runner, hosted platform, console, and program
infrastructure. This is the shared reporting entry point for public and private
Provenance repositories. A report submitted through this form is private; do not
open a public issue, discussion, or pull request with vulnerability details.

Include the affected component and version or commit, reproduction steps,
observed impact, and any known mitigation. Do not include live credentials,
customer data, or unrelated confidential material. Keep reports and follow-up in
the private advisory until maintainers coordinate disclosure.

## Ownership and response

The Provenance security/incident owner (the repository administrator) triages
reports and coordinates fixes with the affected component's maintainers.
The initial response target is two business days. Suspected sandbox escape,
cross-tenant exposure, credential compromise, or publication compromise is
escalated immediately when received.

Fix coordination stays private. Maintainers confirm affected versions and
mitigations before publishing an advisory or other disclosure. Using this
public repository's reporting form does not authorize publication of private
repository source or vulnerability details.
